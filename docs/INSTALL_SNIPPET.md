### Install

Download **one** APK. Most phones need `arm64-v8a`; use `universal` if unsure. Open it
and allow installs from your browser or Files app when Android asks. Updates install
over the previous version and keep all your documents.

Full guide, including how to check the download:
[docs/INSTALL.md](https://github.com/souwmo04/Scanly-mobile/blob/main/docs/INSTALL.md).
